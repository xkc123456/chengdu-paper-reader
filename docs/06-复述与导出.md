# 06 · 复述检验 / 导出落点 / 文献地图

三个功能都只跑在浏览器里：不新增 AI 调用、不额外计费。
它们的共同目的是把「读完一篇」变成「留得下、用得上」。

## 1. 复述检验（Recall）

- 入口：工作台第五个 tab「复述检验」
- 生成：`src/lib/recall.ts` 的 `buildRecallQuestions()` 从解析结果反推，最多 8 题
  （研究问题 → 核心结论 → 3 条讲解 → 机制 → 2 个术语）
- 评分：把参考答案切成 3–14 字的短语作为要点，逐条算字符二元组覆盖率取均值
  - ≥ 0.7 掌握 / ≥ 0.4 基本掌握 / 其余「需要回原文」
- 回跳：点「回原文核对」切到「原文定位」并高亮命中段落（`src/App.tsx` 的 `focusQuote`）
- 记录：按 `标题|领域` 存 `localStorage["cd.recall.<key>"]`，可「只练没掌握的」

**边界（写进 FAQ 了）**：分数只提示「哪里没讲到」，不是考试评分；要点切分是启发式的，
措辞差异大时会低估。不调模型是刻意的：题和分都要可复现。

## 2. 导出落点（Export）

- 入口：工作台右上「导出」
- `src/lib/exportKit.ts` 统一出口，`src/lib/docx.ts` 负责 Word
  - **Word `.docx`**：手写 OOXML + 最小 ZIP 写入器（store、无压缩），不引第三方库。
    含样式表（中文字体、标题层级、A4 页边距）、表格边框；`python-docx` 实测可解析。
  - **Obsidian `.md`**：YAML frontmatter + callout + 双链导航 + mermaid 关系图 +（可选）复述记录
  - **证据表 `.csv`**：一条论断一行（讲解/类比/关系/术语/边界），带 BOM 不乱码
  - **`.json`**：原始结构
- 下载统一走 `downloadFile()`，字符串与 `Uint8Array` 都吃

## 3. 文献地图（Map）

- 入口：工作台「文献地图」
- 数据源：`archive.mine` 列出的本机存档（最多 24 篇）+ 当前这篇（不必先存档）
- `src/lib/libraryMap.ts`
  - `buildMapRows()`：问题 / 结论 / 方法 / 数据 / 边界 / 关键词（方法、数据从章节标题匹配）
  - `themeClusters()`：关键词共现，只收 ≥2 篇的，按篇数降序
  - `singletonKeywords()`：只出现一次的词，用来提示「还没覆盖的角度」
  - `toMapHtml()/toMapMarkdown()/toMapCsv()`：可发给同学、可打印

## 4. 没有 Cloudflare KV 也能用

以前本地 `npm start` 时 `ARCHIVE` / `SHARE` 没有绑定，存档与地图一律 `unavailable`，
功能看起来像没做。现在的做法：

- `api/lib/localstore.ts`：文件型 KV 替身（`get/put/delete/list`，含 prefix + cursor），
  数据落 `.data/store/<name>.json`（已 gitignore），写操作串行化、原子重命名。
- `api/lib/bindings.ts`：进程级默认绑定；`api/server.ts`（仅 Node 入口）启动时注入，
  `api/boot.ts` 组装上下文时先铺默认值、再用平台绑定覆盖。
- Workers 侧不受影响：`node:fs` 不进 Worker 的依赖图，部署时仍走 KV。

## 测试与验证

- 单测：`src/lib/*.test.ts` + `api/lib/localstore.test.ts`（67 个）
- 构建：`tsc -b`、`vite build`、esbuild 服务端打包
- 端到端：
  - Edge headless + CDP：tab 渲染、作答→评分→回跳高亮、导出真的落文件
  - `.docx` 用 `python-docx` 解析：45 段、4 张表、Title/Heading 样式正确
  - 本地存档：`archive.save → mine → get` 走通，`archives.json` 落盘；地图两篇出 3 个主题簇

## 已知限制

- 方法/数据两列依赖章节标题，标题不规范时为空（显示「—」），不猜
- 复述评分是启发式的，措辞差太远会低估
- 本地文件存储是单进程的：多开几个 `npm start` 会各写各的（生产用 KV，无此问题）
