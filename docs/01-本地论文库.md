# WP1 · 本地论文库

> 独占文件：`src/lib/library.ts`、`src/components/LibraryPanel.tsx`、`src/styles/library.css`
> 可小改：`src/App.tsx`（注册入口 ≤10 行）、`src/main.tsx`（引样式 1 行）

---

## 1. 目标与非目标

**目标**
- 解析成功的论文自动/手动存入浏览器，刷新、关页、断网后仍能打开
- 列表可搜索、可重命名、可删除、可导出/导入
- 再次打开**不调用模型**，不花用户 Key 的钱

**非目标（本期不做）**
- 跨设备同步、账号、云备份
- 多端冲突合并
- 全文检索（只搜标题/学科/关键词）

---

## 2. 存储选型

**IndexedDB**，不用 localStorage（5MB 上限、同步阻塞）。

```ts
// src/lib/library.ts
export interface SavedPaper {
  id: string;            // crypto.randomUUID()
  title: string;
  field: string;
  difficulty: "入门" | "适中" | "进阶";
  createdAt: number;     // Date.now()
  updatedAt: number;
  size: number;          // JSON.stringify(result).length，用于配额统计
  sourceHash: string;    // 原文的 SHA-256（去重用）
  sourceText?: string;   // 原文，可选保存（用户可关）
  result: AnalysisResult;
}
```

数据库：`cdreader`，版本 `1`，object store `papers`（`keyPath: 'id'`），索引 `by-created`（`createdAt`）。

## 3. 关键逻辑

### 3.1 保存
- 解析成功（`analyze.onSuccess`）后：若 `autoSave` 开启 → 调 `savePaper()`
- 去重键：`title + sourceHash`
  - 命中 → 弹"已保存过，是否覆盖"（覆盖保留原 `id`，更新 `updatedAt`）
- 单篇上限 **2MB**（超了不存 `sourceText`，只存 `result`，并提示）

### 3.2 容量与淘汰
- 总量上限 **50MB**（`navigator.storage.estimate()` 拿不到时按 `sum(size)` 兜底）
- 超限 → 按 `updatedAt` 最旧淘汰，淘汰前提示"已自动清理 N 篇最旧的"
- 写入失败（配额满/隐私模式）→ 明确文案："浏览器存储空间不足，可导出后删除部分论文"

### 3.3 导出 / 导入
- 导出：单个 `.json`（`{ v: 1, papers: SavedPaper[] }`），文件名 `澄读备份-YYYYMMDD.json`
- 导入：校验 `v`、逐条 `analysisSchema.safeParse`，坏数据跳过并汇报条数
- 同 `id` 冲突：默认"保留较新"，弹窗可改

### 3.4 版本迁移
`onupgradeneeded` 里按 `oldVersion` 分支；以后加字段只加不改。

## 4. UI（LibraryPanel）

一个右侧抽屉（桌面）/ 全屏（窄屏）：

```
┌ 我的论文 (12)                    [导出] [导入] [×]
├ [搜索框]
├ 卡片：标题 / 学科 · 难度 · 8 分钟 / 3 天前
│        [打开] [重命名] [删除]
└ 底部：已用 12.4MB / 50MB
```

- 打开 → 恢复到工作台（设置 `result`、`text`、`isSample=false`、`tab='guide'`）
- 删除 → 二次确认（"删除后不可恢复，建议先导出"）
- 空状态文案要有引导："还没有保存的论文。导入一篇试试，或者先看示例。"

## 6. 验收

- [ ] 解析一篇 → 刷新页面 → 列表里还在，点开五视图正常
- [ ] 断网（DevTools offline）→ 仍能打开已存论文
- [ ] 同一篇重复保存 → 出现覆盖提示，不产生重复条目
- [ ] 导出 → 清空 → 导入 → 内容一致（JSON 往返）
- [ ] 存 60 篇（每篇 ~1MB）→ 触发淘汰且有提示
- [ ] 隐私模式（Safari）→ 写入失败有明确文案，不白屏

## 8. 坑

- Safari 无访问 7 天后会清站点数据 → UI 要提示"建议导出备份"
- `structuredClone` 传 `result` 给 IndexedDB 前先 `JSON.parse(JSON.stringify())`，避免 Proxy/函数报错
- 不要存 `Blob`（PDF 原件），本期只存文本与解析结果
