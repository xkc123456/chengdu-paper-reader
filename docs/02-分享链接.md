> 可小改：`api/router.ts`（挂载 1 行）、`contracts/share.ts`、`wrangler.jsonc`（加 SHARE KV）

---

## 1. 目标与非目标

**目标**
- 点一下生成一条只读链接，别人打开能看到同一套五视图
- 删除可控（生成者持有删除凭证）
- 服务端**只存解析结果**，不存论文原文

**非目标**
- 评论、协作编辑、访问密码
- 公开论文广场/检索
- 跨设备同步（那是账号的事）

---

## 2. 数据流

```
浏览器                      Worker                     KV(SHARE)
  │  POST share.create         │                          │
  │  { result }  ────────────▶ │ 校验 analysisSchema      │
  │                            │ 生成 id / deleteToken    │
  │                            │ put s:<id> ────────────▶ │
  │ ◀──── { id, url, token }   │                          │
  │                            │                          │
访客 │  GET /s/<id>            │                          │
  │  ────────────────────────▶ │ get s:<id> ────────────▶ │
  │ ◀──── 只读渲染 result      │                          │
```

## 3. 契约（`contracts/share.ts`）

```ts
import { z } from "zod";
import { analysisSchema } from "./analysis";

export const shareCreateInput = z.object({
  result: analysisSchema,
  expiresInDays: z.union([z.literal(7), z.literal(30), z.null()]).default(null),
});

export const shareCreateOutput = z.object({
  id: z.string().length(10),
  url: z.string(),          // https://cdreader.top/s/<id>
  deleteToken: z.string(),  // 只回一次，前端存 localStorage
  expiresAt: z.number().nullable(),
});

export const shareGetOutput = z.object({
  result: analysisSchema,
  createdAt: z.number(),
  expiresAt: z.number().nullable(),
});

export const shareDeleteInput = z.object({ id: z.string().length(10), token: z.string() });
```

## 4. 服务端（`api/shareRouter.ts`）

```ts
// KV 键：s:<id>；值：
interface ShareRecord {
  v: 1;
  result: AnalysisResult;
  createdAt: number;
  expiresAt: number | null;   // KV 没有 TTL，读的时候自己判断
  tokenHash: string;          // SHA-256(deleteToken)，不存明文
}
```

要点：
- `id`：`crypto.getRandomValues` → base62 → 取 10 位；写前 `get` 一次防碰撞（概率极低，便宜）
- `deleteToken`：32 位随机串，**只返回一次**；服务端只存 `tokenHash`
- 体积：`JSON.stringify(result).length > 512 * 1024` → 拒绝（`PAYLOAD_TOO_LARGE`）
- 频率：每 IP 每小时 10 次创建（复用 `api/lib/ratelimit.ts`）
- 过期：`expiresAt` 已过 → 返回 `GONE`，顺手 `delete`（惰性清理）
- 删除：`share.delete` 校验 `tokenHash`，不匹配返回 `FORBIDDEN`（不区分"不存在/无权限"，避免枚举）

**路由挂载**（`api/router.ts` 加一行）：
```ts
export const router = createRouter({ paper: paperRouter, profile: profileRouter, site: siteRouter, share: shareRouter });
```

**wrangler.jsonc**：
```jsonc
"kv_namespaces": [
  { "binding": "PROFILES", "id": "..." },
  { "binding": "SHARE", "id": "<新建后填>" }
]
```
> 免费额度：KV 每天 1000 次写、10 万次读。只在"点分享"时写，够用。

## 5. 前端

### ShareDialog
- 触发：工作台右上 `分享`
- 内容：预览缩略（标题/学科/一句话）+ 有效期选择（永久 / 30 天 / 7 天）+ 一条确认勾选：
  > 我只分享解析结果，不包含论文原文；链接公开可见，请勿分享含未公开数据的论文。
- 生成后：显示链接 + `复制` + `删除链接`（带 token）

### SharePage（`/s/:id`）
- 复用工作台的五个视图组件，**隐藏**导入面板、分享按钮、解析按钮
- 顶部一条横幅：`这是一份只读分享 · 由某位同学生成`
- 注入 `<meta name="robots" content="noindex,nofollow">`（动态设置）
- 404 / 410（过期）/ 网络失败 三种文案分开

### 路由
SPA 内用 `location.pathname` 判断 `/s/` 前缀，在 `main.tsx` 或 `App` 最外层分流；**不要**在 Worker 层做 SSR（本期）。

## 6. 安全与合规

- id 不可枚举（10 位 base62 ≈ 8.4×10^17 组合）
- 删除凭证只存 hash；日志**不打印** token、不打印 result
- 分享页 `noindex`，不被搜索引擎收录
- 不做"公开广场"，避免平台变成论文解析内容的集散地（版权与审核风险）
- 用户协议/隐私政策里写清：分享的内容会存到服务端，可随时删除

---

## 7. 验收

- [ ] 生成链接 → 无痕窗口打开 → 五视图与原文一致
- [ ] 复制链接 → 手机打开正常
- [ ] 删除后再次访问 → 404；用错误 token 删除 → 403
- [ ] 7 天有效期到点 → 410，且 KV 记录被清
- [ ] 超过 512KB 的 result → 明确报错
- [ ] 1 小时点 11 次 → 第 11 次 429
- [ ] 服务端日志里搜不到论文正文与 token

## 9. 坑

- KV 是**最终一致**：刚写入立刻读可能读不到（通常 <60s）。生成后跳转要带"稍等"或轮询 3 次。
- Workers 请求体上限 100MB，但我们的限制是 512KB，别忘了解析前先看 `content-length`。
- 只读页要禁掉 `localStorage` 写入（避免访客被"记住"成作者）。
