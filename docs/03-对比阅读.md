## 1. 目标与非目标

**目标**
- 预置**第二篇免费论文**，与第一篇形成"同题、反结论"的对照
- 两篇按同一套维度并排看，差异一眼可见
- 让用户第一次意识到：**读论文要比设计，不是比结论**

**非目标（本期不做）**
- AI 自动归纳差异（要花钱、要提示词、要评估准确率）
- 任意两篇本地论文对比（v1 先固定 A=第一篇，B 可选）
- 引用级对齐（段落/图表逐条对应）

## 2. 第二篇预置论文（教学示例，非真实论文）

**标题**：《数字金融真的缓解了融资约束吗？——一个反向检验》

**为什么选它**：和第一篇同一个研究问题、同一种论文类型（实证），但**结论相反**。这样对比出来的不是"两篇不一样"，而是"**两篇哪里不一样，导致结论不一样**"——这才是精读教学最有价值的场景。

**内容纲要（写作时按此展开，数据自行构造并标注"教学示例"）**

| 部分 | 要点 |
| --- | --- |
| 研究问题 | 同样问 X→Y，但质疑"数据增信"这条机制是否真的成立 |
| 数据 | 某省 2016–2020 银行信贷审批微观数据（企业-年份面板），非公开调查数据 |
| 方法 | 双重差分 + 倾向得分匹配（DID + PSM） |
| 结果 | 控制企业规模与行业后，效应从 −0.9 收窄到 −0.3 且不显著 |
| 解释 | 前文的组间差异主要来自**企业自选择**（本来经营好的企业更早用数字工具） |
| 边界 | 只覆盖一省、以大银行为主、未覆盖小贷与供应链金融 |

**关键：数字要自洽**
- 第一篇：高/低组 2020 年差 1.2（指数）
- 第二篇：DID 估计从 −0.9 → −0.3，标准误 0.21，p=0.15（不显著）
- 两篇的"差异"能对上：一篇看组间趋势，一篇看处理效应

**文件**：`src/lib/sample2.ts`，导出 `sample2Text`（约 800–1200 字）与 `sample2Analysis: AnalysisResult`，schema 必须一次通过 `analysisSchema.parse`。

## 3. 对比数据模型（`src/lib/compare.ts`）

```ts
export type DiffKind = "same" | "different" | "conflict";

export interface CompareDimension {
  key: string;          // 'question' | 'design' | ...
  label: string;        // 展示名
  a: string;            // 第一篇这一维度说了什么
  b: string;
  diff: DiffKind;
  note?: string;        // 一句话解释"为什么不同"
}

export interface CompareView {
  titleA: string;
  titleB: string;
  summary: string;      // 一句话差异，如"同一个问题，两篇的识别策略不同，结论因此相反"
  dimensions: CompareDimension[];
  takeaway: string[];   // 3 条读法建议
}
```

**v1 的差异判定 = 人工标注**（写在 `buildCompareView()` 里），不调模型。原因：准确率 100%、零成本、零延迟。

**七个维度（固定顺序）**

| key | label | 预置标注 |
| --- | --- | --- |
| question | 研究问题 | same |
| design | 研究设计 | different |
| sample | 样本与数据 | different |
| measure | 核心变量度量 | different |
| identification | 识别策略 | different |
| finding | 主要结论 | **conflict** |
| boundary | 适用边界 | different |

> 7 行、4 种颜色层次，视觉节奏刚好；再多会变成"表格读不动"。

## 4. UI（`CompareBoard.tsx`）

```
┌ 对比阅读
│ 同题两篇，结论相反 —— 差在哪？
├ 一句话差异（summary）
├ ┌──────────┬──────────────┬──────────────┐
│ │ 维度      │ A《数字金融…》 │ B《真的缓解…》 │
│ ├──────────┼──────────────┼──────────────┤
│ │ 研究问题  │ …            │ …            │ 灰：相同
│ │ 研究设计  │ …            │ …            │ 蓝：不同
│ │ 主要结论  │ …            │ …            │ 红：冲突
│ └──────────┴──────────────┴──────────────┘
├ 读法建议（3 条）
└ [换一篇对比 ▾]（占位，v2 接本地库）
```

**样式**：
- 行左侧 3px 色条：`same` 灰 `#9aa`、`different` 蓝 `#4a7`、`conflict` 红 `#d55`
- 表头吸顶；`conflict` 行整行浅红底
- 窄屏（<720px）：三栏变卡片流，每个维度一张卡，A/B 上下堆叠，色条保留

**入口与状态（`App.tsx` 小改）**
```tsx
type View = "home" | "compare";
const [view, setView] = useState<View>("home");
// 导航加：<button onClick={() => setView("compare")}>对比阅读</button>
// 分支：view === "compare" ? <CompareBoard /> : <原有内容 />
```

**首页调整（`homeCopy.ts` + `homeStaticHtml.ts`）**
- hero 下加一句：`两篇同题论文，结论相反——点开看看差在哪。`
- 静态正文也加同样一段（无 JS 也能读到），否则 SEO 与可访问性不一致
